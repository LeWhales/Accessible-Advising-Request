enter info such as name, email, day and time needed to get "help"

Requirements

    Use explicit labels, instructions, sensible input types, and grouped controls.
    Implement at least six rules across five fields, including one cross-field rule.
    Return structured validation results from a pure function.
    Render a linked error summary and field-level messages without clearing valid entries.
    Submit keyboard and accessibility-tree test evidence plus a client/server validation explanation.

Minimum test set

    empty form
    one invalid field
    multiple invalid fields
    cross-field conflict
    valid submission
